# Provenant Homebrew tap

Homebrew formula for [Provenant](https://github.com/getprovenant/provenant), a fast Rust code scanner for licenses, copyrights, and package provenance.

## Install

```sh
brew install getprovenant/tap/provenant
```

Or tap first, then install:

```sh
brew tap getprovenant/tap
brew install provenant
```

## What you get

Prebuilt binaries for macOS (Apple Silicon and Intel) and Linux (arm64 and x86_64), pulled from the signed [Provenant release archives](https://github.com/getprovenant/provenant/releases). The formula is bumped automatically on every Provenant release.

For usage, see the [Provenant website](https://getprovenant.dev), the [Provenant README](https://github.com/getprovenant/provenant#readme), and the [CLI Guide](https://github.com/getprovenant/provenant/blob/main/docs/CLI_GUIDE.md).
